# Single-Step QSM with L2-Regularization

MATLAB code and example in vivo data (3D-EPI at 3T, 1 mm isotropic) comparing single-step QSM with a preconditioned conjugate gradient solver against L2-regularized QSM with magnitude weighting.

## Usage

Run `script_3D_EPI_SSQSM.m` from the repository folder in MATLAB.

## Reference

B Bilgic, C Langkammer, LL Wald, K Setsompop. Single-Step QSM with Fast Reconstruction. 2014. [[PDF]](https://www.martinos.org/~berkin/2014_06_25_Single_Step_QSM.pdf)
